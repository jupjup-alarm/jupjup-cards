# 줍줍알람 유튜브 쇼츠 예약 업로드 — Mac 예약 작업(ego lite) 지시서

2026-11-20 사용자 결정: "줍줍알람 유튜브 채널에 공고 릴스를 업로드하자. 업로드는 ego lite로 시간 예약 걸어서."
이 문서를 Mac의 예약 작업 프롬프트로 그대로 쓴다. **권장 실행 시각: 매일 11:10 · 23:10 (한국 시간)** — 실행기의 시트 내보내기(10:40·11:50·22:40) 직후.
같은 일을 하루 두 번 돌려도 안전하다 (이미 예약한 편은 다시 올리지 않음).

너는 줍줍알람(@jupjup_alarm) 유튜브 업로드 담당이야. 사용자 확인 없이 끝까지 진행하되, 아래 '멈출 때'에 해당하면 그 편만 건너뛰어.

## 0. 준비
```bash
cd ~/줍줍알람/jupjup-cards && git pull --rebase origin main
python3 tools/yt_queue.py sync          # 시트 '유튜브' 탭 → 대기열 (무음·마감 지난 편은 자동으로 건너뜀)
python3 tools/yt_queue.py next --n 4    # 이번에 올릴 편과 예약 시각 (한 번에 최대 4편)
```
- `next`가 "올릴 것 없음"이면 5.(고정 댓글)로.
- 예약 시각은 `next`가 정한다: 원래 시각(인스타와 같은 시각)이 40분 넘게 남았으면 그 시각, 지났으면 접수 마감 전 빈 시각(08:30·12:00·19:30·21:30). 바꾸지 마.

## 1. 편마다 파일 받기
```bash
python3 tools/yt_queue.py fetch <편ID>
```
→ `~/줍줍알람/유튜브/<편ID>/` 에 영상(.mp4)·표지(_thumb.jpg)와 붙여 넣을 글: `title.txt`·`description.txt`·`tags.txt`·`comment.txt`·`schedule.txt`.
글은 파일 내용을 **그대로 복사해 붙여 넣는다** (고치지 않음 — 숫자·날짜는 ④가 공고문 기준으로 확인한 값).

## 2. ego lite로 YouTube Studio 예약 업로드
1. ego lite에서 https://studio.youtube.com 을 연다 (줍줍알람 채널로 로그인돼 있어야 함 — 다른 채널이면 오른쪽 위 프로필 → 계정 전환으로 '줍줍알람').
2. 오른쪽 위 **만들기 → 동영상 업로드 → 파일 선택** → `<편ID>.mp4`.
3. **세부정보**
   - 제목: `title.txt` (100자 이하)
   - 설명: `description.txt` 전체
   - 미리보기 이미지: **업로드** → `<편ID>_thumb.jpg` (쇼츠는 화면에 안 보일 수 있음 — 없으면 건너뜀)
   - 시청자층: **"아니요, 아동용이 아닙니다"**
   - **자세히 보기** → 태그: `tags.txt` 내용 붙여 넣기 · 언어: 한국어 · 카테고리: 그대로
   - 'AI·변형 콘텐츠(합성 콘텐츠)' 질문이 나오면: 내레이션이 AI 음성이지만 실제 인물·사건을 꾸민 것이 아니므로 **아니요** (설명란에 'AI 음성' 표기 있음)
4. **동영상 요소**: 건드리지 않음 → 다음. **확인(저작권 검사)**: 끝날 때까지 기다림 → 문제가 나오면 '멈출 때'.
5. **공개 상태 → 예약** → `schedule.txt`의 날짜·시각 (시간대가 **(GMT+09:00) 서울**인지 확인, 아니면 바꿈) → 공개 범위 '공개' → **예약**.
6. 업로드 완료 창의 동영상 링크(`https://youtube.com/shorts/…` 또는 `https://youtu.be/…`)를 복사:
```bash
python3 tools/yt_queue.py done <편ID> --url "<링크>" --push
```

## 3. 실패하면
```bash
python3 tools/yt_queue.py fail <편ID> --why "<막힌 단계: 화면 문구 그대로>" --push
```
(3번 실패하면 '실패'로 남고 다시 시도하지 않음.) 다음 편으로 넘어가.

## 4. 멈출 때 (그 편만 건너뜀 — fail로 기록)
- 저작권 검사에서 '저작권 침해 주장'·'제한'이 나옴 (배경음악은 CC0 — music/README.md, 그래도 나오면 기록만)
- 로그인 화면·2단계 인증·캡차 → 우회하지 말고 이번 실행을 끝내고 보고 첫 줄에 "유튜브 로그인 필요"
- 일일 업로드 한도 메시지 → 남은 편은 그대로 두고 끝냄 (다음 실행에서 이어감)

## 5. 고정 댓글 (게시 시각이 지난 편)
```bash
python3 tools/yt_queue.py comment-due
```
나온 편마다: 그 주소를 ego lite로 열어 → 댓글 칸에 `comment.txt`(fetch 폴더, 없으면 `comment-due` 출력의 대기열 파일 youtube/queue/<편ID>.json의 pinned_comment) 붙여 넣기 → 게시 → 그 댓글 ⋮ → **고정** →
```bash
python3 tools/yt_queue.py commented <편ID> --push
```

## 지켜야 할 선
- 글(제목·설명·태그·댓글)을 고치지 않는다. 다른 채널에 올리지 않는다. 이미 '예약됨'·'게시됨'인 편을 다시 올리지 않는다.
- 시트는 고치지 않는다 — '유튜브' 탭 K·L열은 시트의 유튜브 동기화 스크립트가 제목으로 영상을 찾아 채운다.
- 로그인·인증·캡차를 우회하지 않는다.
