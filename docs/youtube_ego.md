# 줍줍알람 유튜브 쇼츠 예약 업로드 — Mac 예약 작업(ego lite) 지시서

2026-11-20 사용자 결정: "줍줍알람 유튜브 채널에 공고 릴스를 업로드하자. 업로드는 ego lite로 시간 예약 걸어서."
이 문서를 Mac의 예약 작업 프롬프트로 그대로 쓴다. **권장 실행 시각: 매일 11:10 · 23:10 (한국 시간)** — 실행기의 시트 내보내기(10:40·11:50·22:40) 직후.
같은 일을 하루 두 번 돌려도 안전하다 (이미 예약한 편은 다시 올리지 않음).

너는 줍줍알람(@jupjup_alarm) 유튜브 업로드 담당이야. 사용자 확인 없이 끝까지 진행하되, 아래 '멈출 때'에 해당하면 그 편만 건너뛰어.

## 0. 준비
```bash
cd ~/줍줍알람/jupjup-cards && git pull --rebase origin main
python3 tools/yt_queue.py sync          # 시트 '유튜브' 탭 → 대기열 (무음·마감 지난 편은 자동으로 건너뜀)
python3 tools/yt_queue.py next --n 4    # 이번에 올릴 편과 예약 시각 (한 번에 최대 4편)
```
- `next`가 "올릴 것 없음"이면 5.(고정 댓글)로.
- 예약 시각은 `next`가 정한다: 원래 시각(인스타와 같은 시각)이 40분 넘게 남았으면 그 시각, 지났으면 접수 마감 전 빈 시각(08:30·12:00·19:30·21:30). 바꾸지 마.

## 1. 편마다 파일 받기
```bash
python3 tools/yt_queue.py fetch <편ID>
```
→ `~/줍줍알람/유튜브/<편ID>/` 에 영상(.mp4)·표지(_thumb.jpg)와 붙여 넣을 글: `title.txt`·`description.txt`·`tags.txt`·`comment.txt`·`schedule.txt`.
글은 파일 내용을 **그대로 복사해 붙여 넣는다** (고치지 않음 — 숫자·날짜는 ④가 공고문 기준으로 확인한 값).

## 2. ⚠ 채널 확인 — 반드시 '줍줍알람' (투키즈노트 아님)
같은 구글 계정에 **투키즈노트** 채널도 있어서, 그대로 두면 투키즈노트에 올라갈 수 있다. 업로드 전에 매번 확인한다.
- 줍줍알람 채널: 이름 **줍줍알람** · 핸들 **@jupjup_alarm** · 채널 ID **UCbIKC-joj_M279Tii7sLSiA** (`python3 tools/yt_queue.py channel`)
1. ego lite에서 **https://studio.youtube.com/channel/UCbIKC-joj_M279Tii7sLSiA** 를 연다 (이 주소로 열면 줍줍알람 Studio로 바로 들어감).
2. 왼쪽 위 프로필 아래 채널 이름이 **"줍줍알람"**인지 본다.
   - **"투키즈노트"**(또는 다른 이름)면: 오른쪽 위 동그란 프로필 사진 → **계정 전환**(Switch account) → 목록에서 **줍줍알람** 선택 → 다시 1번 주소를 열고 이름 확인.
   - 목록에 줍줍알람이 없으면: 같은 메뉴의 **모든 채널 보기**에서 찾는다. 그래도 없으면(다른 구글 계정에 있음) 업로드하지 말고 이번 실행을 끝내고 보고 첫 줄에 "유튜브 채널 전환 필요: 지금 <채널 이름>".
   - 주소창이 `studio.youtube.com/channel/UCbIKC-joj_M279Tii7sLSiA/…`가 아니면 줍줍알람이 아니다.
3. 편마다 업로드 직전에 한 번 더 왼쪽 위 이름을 본다 (여러 편 올리는 중에 바뀌는 일이 있음).

## 3. ego lite로 YouTube Studio 예약 업로드
1. (2.에서 줍줍알람 Studio가 열린 상태) 오른쪽 위 **만들기 → 동영상 업로드 → 파일 선택** → `<편ID>.mp4`.
2. **세부정보**
   - 제목: `title.txt` (100자 이하)
   - 설명: `description.txt` 전체
   - 미리보기 이미지: **업로드** → `<편ID>_thumb.jpg` (쇼츠는 화면에 안 보일 수 있음 — 없으면 건너뜀)
   - 시청자층: **"아니요, 아동용이 아닙니다"**
   - **자세히 보기** → 태그: `tags.txt` 내용 붙여 넣기 · 언어: 한국어 · 카테고리: 그대로
   - 'AI·변형 콘텐츠(합성 콘텐츠)' 질문이 나오면: 내레이션이 AI 음성이지만 실제 인물·사건을 꾸민 것이 아니므로 **아니요** (설명란에 'AI 음성' 표기 있음)
3. **동영상 요소**: 건드리지 않음 → 다음. **확인(저작권 검사)**: 끝날 때까지 기다림 → 문제가 나오면 '멈출 때'.
4. **공개 상태 → 예약** → `schedule.txt`의 날짜·시각 (시간대가 **(GMT+09:00) 서울**인지 확인, 아니면 바꿈) → 공개 범위 '공개' → **예약**.
5. 업로드 완료 창의 동영상 링크(`https://youtube.com/shorts/…` 또는 `https://youtu.be/…`)를 복사.
6. **올라간 채널 확인**: Studio 왼쪽 **콘텐츠 → Shorts** 목록 맨 위에 방금 제목이 '예약됨'으로 있는지, 왼쪽 위 이름이 **줍줍알람**인지 본다. 맞으면:
```bash
python3 tools/yt_queue.py done <편ID> --url "<링크>" --push
```
7. **투키즈노트 등 다른 채널에 올라갔으면**: 그 채널 Studio에서 그 영상의 공개 상태를 **비공개**로 바꾼다 (지우지 않음 — 사용자가 확인 후 정리). 그다음
```bash
python3 tools/yt_queue.py fail <편ID> --why "다른 채널(<채널 이름>)에 올라가 비공개로 바꿈: <링크>" --push
```
   → 2.로 돌아가 줍줍알람으로 바꾼 뒤 같은 편을 다시 올린다 (fail 후 그 편은 다시 '대기').

## 4. 실패하면
```bash
python3 tools/yt_queue.py fail <편ID> --why "<막힌 단계: 화면 문구 그대로>" --push
```
(3번 실패하면 '실패'로 남고 다시 시도하지 않음.) 다음 편으로 넘어가.

## 5. 멈출 때 (그 편만 건너뜀 — fail로 기록)
- 저작권 검사에서 '저작권 침해 주장'·'제한'이 나옴 (배경음악은 CC0 — music/README.md, 그래도 나오면 기록만)
- 로그인 화면·2단계 인증·캡차 → 우회하지 말고 이번 실행을 끝내고 보고 첫 줄에 "유튜브 로그인 필요"
- 일일 업로드 한도 메시지 → 남은 편은 그대로 두고 끝냄 (다음 실행에서 이어감)

## 6. 고정 댓글 (게시 시각이 지난 편)
```bash
python3 tools/yt_queue.py verify --push   # 게시된 편이 줍줍알람 채널에 있는지 — 다른 채널이면 '⚠'와 함께 대기열로 되돌림 → 7.처럼 비공개로 바꾸고 다시 올림
python3 tools/yt_queue.py comment-due
```
나온 편마다 (댓글도 **줍줍알람** 이름으로 달아야 함 — 댓글 칸 왼쪽 프로필이 줍줍알람인지 확인, 아니면 2.처럼 계정 전환): 그 주소를 ego lite로 열어 → 댓글 칸에 `comment.txt`(fetch 폴더, 없으면 `comment-due` 출력의 대기열 파일 youtube/queue/<편ID>.json의 pinned_comment) 붙여 넣기 → 게시 → 그 댓글 ⋮ → **고정** →
```bash
python3 tools/yt_queue.py commented <편ID> --push
```

## 지켜야 할 선
- 글(제목·설명·태그·댓글)을 고치지 않는다. **줍줍알람 채널(UCbIKC-joj_M279Tii7sLSiA)에만 올린다 — 투키즈노트에 올리지 않는다.** 잘못 올라간 영상은 지우지 말고 비공개로. 이미 '예약됨'·'게시됨'인 편을 다시 올리지 않는다.
- 시트는 고치지 않는다 — '유튜브' 탭 K·L열은 시트의 유튜브 동기화 스크립트가 제목으로 영상을 찾아 채운다.
- 로그인·인증·캡차를 우회하지 않는다.
