대출 도구

주택담보대출 한도 계산기 — LTV·DSR·지역 상한 중 가장 작은 값

집값·소득·다른 대출을 넣으면 LTV로 계산한 한도, DSR로 계산한 한도, 수도권·규제지역의 금액 상한을 각각 구하고 그중 가장 작은 값을 실제 한도로 보여 드려요.

줍줍알람 편집팀2026.11.20 기준 법령·공식 안내 확인입력값은 저장하지 않아요

01세 개의 자물쇠

주담대 한도는 ① 집값 대비 LTV ② 소득 대비 DSR ③ 수도권·규제지역의 금액 상한을 모두 통과해야 해요. 셋 중 가장 작은 값이 실제 한도예요. 대부분은 소득이 기준인 DSR에서 먼저 막혀요.

02LTV — 규제지역 40%

2025년 10월 16일부터 규제지역(투기과열지구·조정대상지역)의 주담대 LTV는 무주택자도 40%예요. 생애최초 구입은 70%(6개월 안 전입 조건), 규제지역 밖은 70%가 기본이에요. 서울 전역과 경기 일부가 규제지역이고 지정은 수시로 바뀌니 공고문·은행에서 확인하세요.

03수도권·규제지역 금액 상한

수도권·규제지역에서 집을 살 때는 LTV와 별개로 주담대가 시가 15억원 이하 6억원, 15억원 초과~25억원 이하 4억원, 25억원 초과 2억원까지만 나와요.

04DSR 40%와 스트레스 금리

은행 DSR은 모든 대출의 1년 원리금이 연소득의 40%를 넘지 않아야 해요. 한도를 계산할 때는 실제 금리에 스트레스 금리를 더해 더 보수적으로 계산해요. 수도권·규제지역 주담대는 3%p를 더하고, 지방은 그보다 낮게 더해요. 스트레스 금리는 한도 계산에만 쓰이고 실제 이자에는 붙지 않아요.

예시숫자로 한 번 보면

연소득 7,000만원, 다른 대출 없음, 서울 9억원 아파트, 금리 4.2%·스트레스 3%p·30년이면 LTV 40% = 3억6,000만원, DSR 기준(7.2%로 계산) 약 3억4,370만원, 상한 6억원 → 실제 한도는 가장 작은 DSR 기준 약 3억4,370만원이에요.

자주 묻는 질문

중도금 대출에도 이 한도가 적용되나요?

중도금 집단대출은 DSR이 적용되지 않는 대신 보증기관 한도와 규제지역 LTV가 적용돼요. 잔금 때 주담대로 바꿀 때 이 계산기의 한도가 다시 적용돼요.

정책대출(디딤돌·보금자리론)은요?

정책대출은 소득·집값 요건과 상품별 한도가 따로 있고 DSR 대신 DTI를 쓰는 경우도 있어요. 은행·주택금융공사에서 따로 확인하세요.

고정금리면 한도가 늘어나나요?

고정금리 기간이 길수록 스트레스 금리를 적게 더해서 한도가 조금 늘어요. 계산기의 스트레스 금리 칸을 낮춰서 비교해 보세요.
