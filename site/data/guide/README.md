# 가이드 칼럼 원고 형식 (site/data/guide/{slug}.json)

jupjupalarm.com/guide/{slug}/ 로 나가는 칼럼. 공고 페이지와 달리 한 번 깊게 쓰고 분기마다 점검하는 글이다.
목표: 애드센스 심사에서 '가치가 낮은 콘텐츠'로 보이지 않을 만큼 독자적이고, 검색으로 들어온 사람이 이 글 하나로 결정을 내릴 수 있게.

## 파일 하나 = 칼럼 하나 (UTF-8 JSON)
```json
{
  "slug": "cheongyak-gajeom",                 // 영문 소문자·숫자·하이픈. 한 번 정하면 안 바꿈
  "category": "청약 자격",                     // 청약 자격 | 무순위 | 임대 | 대출 | 신도시
  "title": "청약 가점 계산법 — 84점의 구조와 계산기",  // <title> (뒤에 ' · 줍줍알람'은 빌드가 붙임). 대표 키워드가 맨 앞, 40자 안팎
  "h1": "청약 가점 84점, 어떻게 계산하나요?",    // 질문형
  "dek": "무주택 기간 32점, 부양가족 35점, 통장 가입기간 17점. 세 칸만 알면 내 점수를 가늠할 수 있어요.",  // 60~100자
  "description": "검색 결과 설명 120자 안팎 (없으면 answer[0])",
  "basis": "2026.10",                           // 기준 (법령·제도 기준 시점)
  "published": "2026-10-29", "checked": "2026-10-29",
  "keywords": ["청약 가점 계산기", "청약 가점", "무주택 기간", "부양가족 수"],
  "answer": ["먼저 결론 1문장", "2", "3"],      // 각 60자 안팎, 검색 요약에 잡히는 자리
  "cover": {"svg": "<svg viewBox='0 0 640 260' …>…</svg>", "svg_narrow": "<svg viewBox='0 0 340 …'>…</svg>",
            "alt": "그림 설명", "caption": "근거: 주택공급에 관한 규칙 별표 1"},
  "body": "마크다운 본문 (아래 문법)",
  "faq": [["질문", "답"], …],                   // 4~6개, 검색 롱테일 말투
  "sources": [{"name": "주택공급에 관한 규칙 별표 1", "url": "https://www.law.go.kr/…", "note": "가점제 적용기준"}],
  "facts": [{"item": "무주택 기간 만점", "value": "32점", "source": "주택공급에 관한 규칙 별표 1", "effective": "2024.3.25 시행"}],
  "related": ["다른 칼럼 slug", …],             // 2~3개 (아직 없는 글이어도 됨 — 있는 것만 링크됨)
  "notice_kinds": ["private", "public"],        // '지금 접수 중인 공고'에 붙일 공고 유형: mujeonwi private public newlywed rental (없으면 [])
  "notice_match": ["매입임대"]                   // (선택) 공고 제목·kind_label에 이 말이 들어간 것만
}
```

## 본문 문법 (body)
- `## 장 제목` — 4~6개. 장 제목 = 사람들이 실제로 검색하는 질문 (keywords 참고). 번호·id는 빌드가 붙임.
- 일반 마크다운: 단락, **굵게**, 목록, 표(파이프 표: 첫 줄 머리, 단위는 머리에), `[글자](주소)`.
- 상자:
  ```
  :::note 자주 하는 실수
  미혼인데 20대 때부터 무주택 기간을 세는 경우가 많아요. …
  :::
  ```
  `:::tip 종이 한마디` (한 편에 한 번만, 짧게) · `:::check 놓치기 쉬운 것` (안에 `- 항목` 5줄 안팎)
- 예시 가구: `:::cases` 안에 `### 가구 이름` + 내용 (2~3개). 모두 가상이고 빌드가 '예시' 표시를 붙임. 숫자는 직접 계산해 맞출 것.
- 그림: `:::figure 캡션` 다음 줄부터 SVG 한 덩어리, `:::`로 닫기. viewBox 너비 640, 글자 12px 이상.
- 도구: `:::tool gajeom` (청약 가점 계산기) · `:::tool dsr` (DSR·LTV 대출 한도 계산기) · `:::tool selfcheck` (예/아니오 체크 — 아래) 한 줄.
  ```
  :::tool selfcheck 무주택 세대구성원일까요?
  - 세대주와 세대원 모두 주택(분양권·입주권 포함)이 없다
  - …
  결과: 모두 '예'면 무주택 세대구성원일 가능성이 커요. 최종 판정은 공고문 기준이에요.
  :::
  ```
- 날짜 표기: 11.2(월) 같은 공고 표기 대신 칼럼은 "2026년 10월", "2025.6.27 대책" 식.

## 그림(SVG) 색
남색 #0F1E3D · 코랄 #FF5233 · 진한 코랄 #C8361A · 연한 코랄 #FFF1EC · 회색 #9AA3B2 · 선 #E3E7ED · 띠 #F4F6F9 · 보조 글자 #5B6472 · 파랑 #1E4FD8 · 초록 #0E7A5F.
글꼴은 지정하지 않는다(사이트 글꼴을 물려받음). 커버는 글 전체를 한 장으로 보여주는 구조도(비교·흐름·구성). 사진·로고·다른 사이트 이미지 금지.
cover.svg = 가로형(PC), svg_narrow = 같은 내용을 세로로 쌓은 모바일용 (viewBox 너비 340).

## 쓰는 규칙
- 분량: body 4,000~6,000자. 존댓말 해설체("~예요"), 문장 짧게, 한 단락 2~4문장.
- 1차 출처만: 국가법령정보센터(law.go.kr) 법령·별표, 국토교통부·금융위원회 보도자료, 청약홈·LH청약플러스·마이홈포털·주택도시기금(nhuf.molit.go.kr)·한국주택금융공사(hf.go.kr) 안내, 공식 신도시 사이트. 블로그·카페·언론 문장은 근거로 쓰지 않는다(언론은 '발표 사실' 확인용으로만, 출처에 기관 발표를 적는다).
- 숫자·기준은 facts[]에 하나씩 (항목·값·출처·시행일). 본문 숫자는 facts에 있는 것만.
- 자주 바뀌는 금액(소득·자산 기준, 금리, 한도)은 값 옆에 기준 시점("2026년 기준")을 쓴다. 해석이 갈리는 부분은 단정하지 말고 "공고문·은행 확인"으로.
- 대출: 금리·한도는 발표 기준일을 적고 "실제 한도는 심사 결과에 따라 달라요". 특정 은행·상품 홍보 금지.
- 신도시: 사업 일정·공급 호수는 국토부·LH 발표 기준과 발표일. 집값 전망·투자 권유·정책 평가 금지 (사실과 일정만).
- 다른 칼럼과 같은 문장을 돌려쓰지 않는다. '무조건', '역대급', '꼭 되는' 같은 말 금지.
- 출처 3~6개 (실제로 열어 본 페이지만).
