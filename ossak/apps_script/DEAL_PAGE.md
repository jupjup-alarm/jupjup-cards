# 클로드 코드 작업 지시서 — 딜 단독 페이지 + 핫딜방 페이지 (autodm.jupjupalarm.com)

작성 2026-11-23 · 대상: 정대장 님 맥북의 Claude Code · 관련: `KAKAO_OVERRIDES.md`, `INFLUENCER_STORE.md`, `HOTDEAL_CAPTURE.md`

## ★ 범위 (정대장 님 결정 2026-11-23)
**쿠팡 수량 역전 딜만** 이 구조로 보낸다. 일반 딜과 토스 딜은 autodm을 거치지 않고 지금처럼 원래 링크(파트너스 링크·토스 쉐어링크)를 카톡에 바로 넣는다.
아래 본문 중 일반 딜·토스 딜에 관한 부분(썸네일·이동·목록)은 모두 무시한다.

## 0. 왜
카톡 링크 미리보기는 링크 페이지의 og:title·og:image를 그대로 보여 준다. 쿠팡 링크를 바로 넣으면 쿠팡이 정한 썸네일만 나온다.
경쟁 채널처럼 **우리 도메인의 딜 단독 페이지**를 카톡에 넣고, 그 페이지가 ① 카톡 미리보기에는 우리가 만든 썸네일(상품 사진 + 옵션 가격 캡처)을 보여 주고 ② 사람이 열면 바로 쿠팡(역전 딜은 인플루언서 페이지, 나머지는 파트너스 링크) 또는 토스 쉐어링크로 보낸다.

## 1. 어디에
- 이미 있는 Cloudflare Worker `insta-autodm` (https://autodm.jupjupalarm.com). 핫딜방 페이지 `/room`이 여기 있다. 같은 Worker에 경로를 더한다. 기존 경로(`/room`, `/2kids`, `/jj/…`, `/api/…`)는 바꾸지 않는다.
- 새 경로:
  - `GET /d/{id}` — 딜 단독 페이지 (id는 8자 안팎 영문·숫자, 예 `r37a9x2k`)
  - `GET /room` — 기존 핫딜방 페이지에 **최근 딜 목록**을 자동으로 붙인다 (3번).

## 2. 딜 데이터
- 맥 카톡 큐가 **역전 딜** 메시지를 만들 때 딜 하나마다 `hotdeal/deals/{id}.json`을 jupjup-cards main에 올린다 (queue.json과 같은 방식):
  `{"id","row","created","shop":"coupang|toss","kind":"역전|일반|토스","name","priceLine","pair":"10개 10,490원 → 24개 9,820원"|null,"target":"<최종 링크>","disclosure":"<대가성 문구>","og":"hotdeal/og/{id}.jpg"}`
  - `target`: W열 인플링크(인플루언서 페이지), 없으면 내 파트너스 링크. **남의 링크는 절대 넣지 않는다.**
- 목록 `hotdeal/deals/index.json`: 최근 48시간 딜 id·이름·가격·썸네일·종류, 최신순 최대 60개.
- Worker는 GitHub 원문(raw)에서 읽고 60초 캐시한다. 못 읽으면 `/room`으로 보낸다.

## 3. 썸네일 (og:image)
- 맥이 딜마다 `hotdeal/og/{id}.jpg` (1200×630, 200KB 안팎)를 만든다.
  - 역전 딜: 왼쪽 상품 사진 + 오른쪽 옵션 가격 캡처(P열), 고른 옵션에 빨간 테두리. 상품 사진은 캡처기가 상품 페이지를 열었을 때 대표 이미지 부분을 같이 잘라 둔다 (페이지를 다시 열지 않는다).
  - 일반 쿠팡 딜: 상품 사진 + 큰 가격·할인율 글자 (캡처가 없으므로 직접 그림).
  - 토스 딜: **상품 이미지를 쓰지 않는다** (토스는 상품 이미지 크롭·합성 금지). 상품명·가격·할인율 글자 카드만.
- og:title = 상품명, og:description = "상품 정보와 가격을 확인해 보세요."

## 4. `/d/{id}` 동작
- 카톡 미리보기 수집기(User-Agent에 `kakaotalk-scrap` 등)와 다른 봇에는 **og 태그가 든 HTML**을 준다.
- 사람에게는 같은 HTML을 주되, 맨 위에 대가성 문구 한 줄과 상품명·가격, 큰 버튼 "쿠팡에서 보기 →"(토스는 "토스쇼핑에서 보기 →")를 보여 주고 **바로 이동**한다 (`location.replace(target)`, 실패 대비 버튼 유지). 정대장 님 결정(2026-11-23): 열면 바로 넘어가게.
  - 주의: 토스는 "자동 실행" 방식(접속만 해도 앱이 열리는 것)을 금지한다. **토스 딜은 자동 이동하지 말고 버튼을 눌러야 넘어가게** 한다.
  - 쿠팡도 자동 이동에 대한 규정이 바뀔 수 있으니, 자동 이동은 설정값 `AUTO_REDIRECT_COUPANG=true`로 두어 끌 수 있게 한다.
- 클릭 수를 Worker KV에 `{id}: count`로 센다 (사람 접속만). `/api/hotdeal-stats`로 최근 딜별 클릭 수를 볼 수 있게 한다 (비공개 키 필요).

## 5. `/room` 핫딜방 페이지
- 기존 화면 위에 "실시간 핫딜" 목록: index.json의 **역전 딜** 카드(썸네일·상품명·가격·역전 딱지), 누르면 `/d/{id}`.
- **하단 플로팅 CTA "카톡 핫딜방 들어가기"는 그대로 유지** (정대장 님 요청).
- 페이지 맨 위에 대가성 문구 (쿠팡 파트너스·인플루언서·토스 쉐어링크 각각 해당 시 — 목록에 섞여 있으면 세 문구를 모두 짧게).

## 6. 카톡 메시지
- **역전 딜만** 링크 줄을 `https://autodm.jupjupalarm.com/d/{id}`로 바꾼다. 일반 딜·토스 딜 메시지는 지금 그대로(원래 링크). 나머지 양식·두 번째 말풍선·맨 위 대가성 문구(쇼핑몰별)는 그대로.
- 메시지를 큐에 넣기 **전에** deals/{id}.json과 og/{id}.jpg가 공개 주소에서 열리는지 확인한다 (raw는 갱신이 늦을 수 있으니 최대 2분 대기). 안 열리면 예전처럼 쿠팡·토스 링크를 직접 넣는다.

## 7. 완료 기준
1. `/d/{id}`를 카톡 '나와의 채팅'에 붙였을 때 미리보기에 우리 썸네일과 상품명이 뜬다.
2. 폰에서 누르면 바로 쿠팡 인플루언서 페이지(없으면 파트너스 링크)로 간다. 일반 딜·토스 딜 카톡 메시지에는 autodm 주소가 없다.
3. 이동한 쿠팡 주소에 정대장 님 ID(`AF3230467`, 인플루언서면 인플루언서 경로)가 붙어 있다.
4. `/room`에 최근 딜이 자동으로 뜨고 플로팅 CTA가 그대로다.
5. 기존 `/room`·`/2kids`·`/api/…` 동작이 그대로다.
6. 클릭 수가 KV에 쌓인다.

## 추가 (2026-11-23 오후) — X열 '딜페이지'
- 스레드 발행기가 역전 딜 글에 **링크 답글**(딜 페이지 주소 + 대가성 문구)을 단다. 발행기는 주소를 모르므로, 맥이 `/d/{id}` 페이지를 만들고 공개 확인까지 끝나면 시트 **X열('딜페이지')**에 `https://autodm.jupjupalarm.com/d/{id}`를 적는다. X1 헤더가 비어 있으면 채운다.
- 쓰는 순서: W(인플링크) → X(딜페이지). 발행기는 X가 있을 때만 링크 답글을 달고, W가 있으면 인플루언서 문구, 없으면 파트너스 문구를 쓴다.
- X가 없으면 링크 답글 없이 올라간다 (막지 않음).
