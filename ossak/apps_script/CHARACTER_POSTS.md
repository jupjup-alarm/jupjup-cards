# 클로드 코드 작업 지시서 — 특가반장 캐릭터 글 만들기 (맥북, 무료)

작성 2026-11-25 · 대상: 정대장 님 맥북의 Claude Code · 관련: `Hotdeal.gs`(스레드 발행기)

## 목표
스레드에 올릴 딜마다 **'특가반장' 캐릭터 말투의 짧은 글**을 만들어 시트 **AF열('캐릭터글')**에 적는다.
스레드 발행기는 AF열에 글이 있고 검사를 통과하면 그걸 본문으로 쓴다 (없거나 걸리면 정보형 글로). API 키·유료 호출은 쓰지 않고, 이 맥의 `claude -p`(이미 쓰는 구독)로 만든다.

## 대상 행
- '필터통과'에서 J열이 `신규`·`대기`이고 **스레드 후보인 행**: Q열에 역전 쌍이 있거나, E열 할인율이 55% 이상(쿠팡 일반 딜). 토스·네이버 딜은 제외. 이미 AF가 있는 행은 건너뛴다.
- 새 딜이 들어온 뒤 **발행기가 고르기 전에** 적어야 한다: Q열(수량비교)을 쓴 직후 같은 실행 안에서 바로 만들고, 10분 안에 못 만들면 건너뛴다(발행기는 정보형으로 올림).
- 하루 최대 30건, 호출 사이 5초 쉬기.

## 입력 (사실만 준다)
행 데이터로 아래 줄만 만든다. **이 밖의 정보를 프롬프트에 넣지 않는다**(원글 K열 문구, 후기, 판매량 등).
```
상품: {Y열 상품명 또는 제목에서 뽑은 이름} {용량이 있으면}
가격: {D열}원 ({배송 문구가 있으면})
할인율: {E열 할인N%}%
옵션 비교: {Q열 그대로, 예: 1개 3,590원 → 6개 4,640원}
개당: {A개당}원 → {B개당}원 ({N}% 쌈)     # Q열이 있을 때만, 직접 계산
추가금: {B가격-A가격}원                       # Q열이 있을 때만
```

## 프롬프트 (시스템)
```
너는 스레드 계정 "특가반장"의 글을 쓰는 캐릭터다.
캐릭터: 가격표와 계산기만 믿는 동네 반장. 무뚝뚝하지만 정 많고 약간 허세. 반말, 짧은 문장, 가끔 "ㅋㅋ"·"ㄹㅇ" 정도만(과하지 않게). 이모지는 많아야 1개.
버릇: 숫자를 직접 계산해서 보여준다("계산해봤음"). 살지 말지 결론은 한 줄로 단호하게. 사람들을 "얘들아" 또는 "반원들"이라고 부른다.
절대 금지: ① 써봤다·먹어봤다·샀다·후기·내 경험 ② 가족(남편·애·엄마) ③ 판매량·리뷰 수·평점 ④ 입력에 없는 숫자·사실 ⑤ 링크·해시태그 ⑥ "최저가 보장"·"무조건"·"역대급" 같은 과장.
쓸 수 있는 것: 입력에 있는 가격·수량·단가·할인율의 계산과 비교, 그에 대한 반응과 의견("이 가격이면 쟁여도 됨"), 독자에게 던지는 질문.
형식: 3~5줄, 전체 220자 이내. 첫 줄에 상품명(브랜드 포함)과 핵심 숫자 하나. 마지막 줄은 독자에게 묻는 질문 한 줄. 글만 출력한다(설명·따옴표 금지).
```

## 검사 (쓰기 전에 직접 한 번 더)
- 260자 이하, 링크·해시태그 없음.
- 위 금지 표현(써봤·후기·남편·판매량·무조건·역대급 등)이 없음.
- 글 속 두 자리 이상 숫자는 모두 입력에 있는 숫자여야 함 (발행기가 같은 검사를 다시 한다).
- 걸리면 1번만 다시 만들고, 또 걸리면 AF를 비워 둔다.

## 쓰기
- AF1 헤더가 비어 있으면 `캐릭터글`. 글은 `--input RAW`로 쓴다. A~AE는 건드리지 않는다.
- 같은 캐릭터가 같은 말버릇을 반복하지 않게, 최근 올린 글 5개(AF열)의 첫 줄을 프롬프트 끝에 "이 표현은 피해라"로 덧붙인다.

## 완료 기준
1. 역전 딜 1건, 일반 딜 1건에서 AF열 글이 만들어져 검사를 통과한다.
2. 입력에 없는 숫자나 후기 표현이 든 글은 AF에 쓰이지 않는다 (일부러 시험).
3. `hotdealStoryTest`(Apps Script)가 그 글을 보여 준다.

## 추가 (2026-11-26) — 입력에 없는 상품 정보 금지 (숫자가 없어도)
캐릭터 글에 "선물용으로도 쇼핑백 있어서 좋음", "가격 흔들릴 일도 없음" 같은 **입력에 없는 상품 특징·가격 유지 주장**이 나왔다. 숫자가 없어도 지어낸 정보다.
- 프롬프트 '절대 금지 ④'를 이렇게 바꾼다: `입력에 없는 숫자·사실(상품 특징·맛·품질·포장·선물 적합성·가격이 유지된다는 말 포함)`.
- 말할 수 있는 건 **입력의 가격·할인율·수량·단가 계산과 그에 대한 반응·결론·질문**뿐이다. 상품이 어떤지(좋다·맛있다·튼튼하다)는 말하지 않는다.
- 쓰기 전 검사에 아래 표현이 있으면 AF를 비운다(발행기도 같은 검사를 한다): `가격 흔들·안 변·그대로·유지`, `맛있·품질·퀄리티·튼튼·내구`, `선물·쇼핑백·포장·구성품·사은품`, `국내산·정품`, `인기·베스트`.
