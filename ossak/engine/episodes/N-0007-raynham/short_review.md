# N-0007 레이넘 홀 — 처음 보는 사람 검수 기록 (2026-11-03)

결과: 3.0 → 3.5 → 3.5점, 4점 기준 미달로 **탈락**. 시트에 넣지 않음. 그림 13장(r01~r13)은 이미 그려 둠(vpanels, 커밋 안 함). 원고는 마지막 판(short.json).

## 공통 지적
- 클라이맥스(플래시 → 빈 계단) 바로 뒤에 "10년 전 두 소년" 회상으로 빠져 필름 결과가 9초 넘게 미뤄짐 → 가장 큰 이탈 지점. 시간이 두 번 왔다 갔다 함.
- 필름 속 형체가 '무언가'로만 나와 공개 장면이 흐림(3판에서 '베일을 쓴 듯한 흐릿한 형체'로 고쳤으나 여전히 3.5).
- '카메라 흔들림' 설명은 어떻게 사람 모양이 생기는지 감이 안 와 반론이 약함. '여섯 초'는 앞에 깔리지 않으면 튐.
- '저택 화보 촬영'은 패션 화보로 들림 → 제목 후보 "귀신 나온다는 저택 촬영 중".
- 초상화 = 갈색 옷의 여인이라는 연결을 한 번 더 분명히.
