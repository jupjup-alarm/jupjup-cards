# N-0003 콘티 설계도 (PD 기획서 기준)

- 중심 질문: 임금이 "괴이할 것 없다"고 넘긴 그것은, 15일 뒤에도 그 집에 있었나 — 그리고 그것은 무엇이었나?
- 의문 3단계: ① 대낮에 나타나 말하고 음식을 먹는다(소문) → ② 주인은 소리만 들었는데 종들은 말을 주고받았다 → ③ 다른 집으로 피하자 따라왔다.
- 답 한 문장(공포 모드): 답은 없다. 돌아오자 사라졌고(복선 회수), 기록에 남은 건 종들이 본 '허리 아래, 해진 흰 치마'뿐. 설명은 "장난이었을 수도"로 짧게.
- 복선: 4장 임금의 말 "부엉이는 궁궐 나무에서 늘 운다. 괴이한 것은 오래되면 저절로 사라진다" + 궁궐 나무의 부엉이 그림 → 13장에서 같은 그림 재사용("임금의 말처럼, 저절로 사라진 걸까요?"), 16장 부기도 나뭇가지 위.
- 시간 순서: 11/10 경연 → 11/25 재질문 → 이두 진술(9월부터) → 피신 → 귀가 → 종들이 본 모습(가장 무서운 디테일, 15장).
- 매달린 문장: 14장 "전부가 아니었습니다" → 15장 즉시 회수.
- 표지 훅: "대낮에 나타나 음식을 먹는 여자. 임금이 물었다 '아직도 있느냐'" (소재조사 훅의 '허리 아래'는 15장 클라이맥스라 표지에서 뺌).
